Web Designing Notes



What is Internet

Internet is the worldwide network of interconnected network that communicate with IP protocols. It is the massive global system of connected computer network. It links billions of devices worldwide using shared set of rules using internet protocols. In this network people share data , information , send messages , new websites , download files from anywhere. It allows users to exchange information , access websites , send emails, watch videos , download files , and use any online services.
Features Of Internet:
  • Global Connectivity
  • Fast Communication
  • Information Sharing
  • Online Shopping
  • E-Learning
  • Social Networking
  • Cloud Computing

HTML

HTML is the standard language used to create a structured content on the web. It uses tags to define elements like heading, paragraph, links and images that tells the browser how to display the page.

WWW(World Wide Web)

The world wide web commonly called web, is a system of interlinked hypertext documents accessed by the internet.

Browser

A web browser is a software used to access , retrieve and display content on the www.

Functions of a Browser

Send Request to web servers using http/https. Interprets HTML , CSS and JavaScript to display pages. Manages bookmarks , history , cookies and caches. Supports multiple tabs/windows and extensions. Ex- Google Chrome , Microsoft Edge , Mozilla Firefox , Safari , etc.

How Browser Works

  • User types a URL or clicks a link.
  • Browser sends a HTTP request to the web server.
  • Server Processes the request and sends back the HTML Page.(Response)
  • Browser renders the HTML, CSS , JavaScript into a visual page.

Web Server

A Web Server is a computer hardware/software that stores , processes and delivers web pages to clients upon request using HTTP/HTTPS.

Working

  • Browser send a HTTP request.
  • Server locates the requested file/resource.
  • Server Sends the file back as an HTTP response.
E.g.- Apache HTTP Server, Microsoft IIS, NGINX.
